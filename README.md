# 🐀 RatLang Frontend
RatLang is lightweight, versatile language designed for mathematical expression but is not limited to that.
It is focused on simplicity and readability.

## 🔹 Features
- Simple syntax
- Basic control flow
- Functions

## 🛠️ Installation
```Bash
git clone https://github.com/Ratman141/RatLang.git
cd RatLang
```
