# 🐀 RatLang 
RatLang is a revolutionary math-based programming language
that won't add anything new.  
It is focused on simplicity and readability.

## 🔹 Features
- Simple syntax
- Basic control flow
- Functions
- Standard Libraries

## 🛠️ Installation
```Bash
git clone https://github.com/Ratman141/RatLang.git
cd RatLang
./build.sh
```

## ▶️ Running your code
```Bash
./ratlang.sh --help             // For basic info about existing commands
./ratlang.sh --run <file.rl>
```
